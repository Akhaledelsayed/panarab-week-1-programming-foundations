# Week 1 - Programming Foundations, Data Structures & OOP

This project demonstrates basic object-oriented programming in PHP using a simple student record management system.

## Concepts Covered

- Classes and objects
- Encapsulation
- Inheritance
- Arrays as in-memory storage
- Basic CRUD-style operations
- Validation and exception handling

## Files

- `Person.php`: Base parent class.
- `Student.php`: Child class that extends `Person`.
- `StudentManager.php`: Manages adding, listing, finding, updating, and deleting students.
- `main.php`: Demonstration script.
- `index.php`: Entry point.

## How to Run

```bash
php index.php
```
